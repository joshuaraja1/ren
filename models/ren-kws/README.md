# Ren wake model

These ONNX weights and tokens are the quantized chunk-8 subset of
`sherpa-onnx-kws-zipformer-zh-en-3M-2025-12-20` by pkufool, downloaded from
the [sherpa-onnx KWS release](https://github.com/k2-fsa/sherpa-onnx/releases/tag/kws-models).
The model publisher states Apache License 2.0 in
[the licensing discussion](https://github.com/k2-fsa/sherpa-onnx/issues/3802).
`keywords.txt` includes English pronunciations of “Hey Ren,” “Hey Ran,” “Hey Run,” and “Hey Ryan.”
The downstream transcript gate still requires a matching wake phrase before Ren answers.
Inference is local.
