# Delivery roadmap

Each milestone is designed to land as an independently reviewable pull request.

- [x] M0 — public repository, MIT license, and project identity
- [ ] M1 — product requirements, architecture, governance, issue templates
- [ ] M2 — secure Electron shell and distinctive assistant interface
- [ ] M3 — capture, voice, provider adapter, and visual overlay loop
- [ ] M4 — automated tests, CI, staging artifacts, and release documentation
- [ ] M5 — domain capability SDK and first math/OCR capability
- [ ] M6 — CAD and 3D-print integrations through documented host APIs

The first four milestones form Ren 0.1. Later milestones should be proposed as
RFCs and must include permission, privacy, and failure-mode analysis.
