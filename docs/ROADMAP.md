# Delivery roadmap

Each milestone is designed to land as an independently reviewable pull request.

- [x] M0 — public repository, MIT license, and project identity
- [x] M1 — product requirements, architecture, governance, issue templates
- [x] M2 — secure Electron shell and distinctive assistant interface
- [x] M3 — capture, voice, provider adapter, and visual overlay loop
- [ ] M4 — native local wake providers, ambient overlay QA, and focused-window capture
- [x] M5 — automated tests, CI, staging artifacts, and release documentation
- [ ] M6 — automatic temporal context, system-audio transcript, and visual OCR
- [ ] M7 — circle-to-focus and invisible CAD/3D-print context enrichment
- [ ] M8 — voice-created agents with visible plans and approved actions in other apps ([requirements](VOICE_AGENTS.md))
- [ ] M9 — connected visual lessons with a fast diagram and optional realistic imagery ([requirements](VISUAL_TEACHING.md))

Circle-to-focus has an initial implementation; the milestone stays open until
physical multi-monitor gesture QA and CAD/3D-print context enrichment land.

The first four milestones form Ren 0.1. Later milestones should be proposed as
RFCs and must include permission, privacy, and failure-mode analysis.
