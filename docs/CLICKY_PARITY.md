# Published Clicky comparison (November 24, 2026)

Source: [HeyClicky home](https://www.heyclicky.com/),
[changelog](https://www.heyclicky.com/changelog), and
[trust page](https://www.heyclicky.com/trust). These are published product
claims, not an independent audit of its installed app. Ren's status below is
based on this repository.

| Experience | Ren today | Next acceptance gate |
| --- | --- | --- |
| Top-edge assistant that wakes by voice | Bundled offline “Hey Ren” detector and pebble | Real microphone testing on macOS and Windows |
| Ask aloud or type about any visible app | Local English dictation, typed questions, cursor-display screenshots, vision adapter | Test noisy video, CAD, math, accents, and dictation corrections |
| Hold a shortcut and circle a region | Control+Option gesture (Control+Alt on Windows/Linux), visible selection, focused crop and automatic explanation | Hardware QA for global input permission and every display layout |
| Spoken answers and drawings | Speech synthesis; validated arrows, paths, points, text and diagrams. Drawings hide after scrolling or display changes to avoid pointing at stale locations | Anchor drawings to scrolled content; test display changes |
| Guided follow-up | Bounded conversation history and tappable model-suggested questions | Evaluate question quality and show progress through a lesson |
| Privacy | No continuous screen recording; on-demand frames in memory; local wake and transcription; configured provider shown in the panel | Add a capture audit and independent privacy review |
| Mac and Windows packages | Unsigned staging artifacts on both | Signed, notarized releases and physical permission QA |
| Connected-app agents and computer control | Not implemented | Separate opt-in design and safety review; not required for the learning loop |
| Proactive tasks, routines, billing | Not implemented | Product decision after the core teacher experience is dependable |

Ren's primary goal is the screen-aware teacher, not exact imitation. The
published Clicky experience is substantially broader than this prototype.
Feature claims here should be updated only after end-to-end verification.
