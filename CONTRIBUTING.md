# Contributing to Ren

Thank you for helping build a learning tool people can trust.

1. Open an issue for material behavior or architecture changes.
2. Keep pull requests focused on one requirement or decision.
3. Add or update tests for user-visible behavior.
4. Run `npm run check` before requesting review.
5. Explain privacy, accessibility, and platform effects in the PR body.

Ren follows conventional commits. By participating, you agree to the project
code of conduct.
